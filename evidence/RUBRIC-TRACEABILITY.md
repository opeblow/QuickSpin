# Rubric Traceability

| Judge dimension | Product answer | Evidence / artifact | Demo scene |
| --- | --- | --- | --- |
| Waiting experience | optional playable layer, anti-flash threshold, collapse/resume, signed perceived wait | `src/sdk/widget.ts`, persistence tests | 12s before/after + Wait Receipt |
| Originality | observable execution becomes game content rather than decorative status copy | Runner/Orbit signal mechanics | collect execution token |
| AI-native fit | phases, progress, completion, tool/retrieval/artifact/warning signals come from host runtime | `ExecutionSignal`, `WaitSession` | event log + signal token |
| Repeatability | reusable SDK contract, two games, React + vanilla mounting | SDK build outputs, README | switch games / integration block |
| Execution quality | lifecycle state machine, persistence, accessibility, release checks, CodeQL | CI, tests, release workflow | fast inspection / Q&A |
| Evidence honesty | no fake percent, signed receipt, failed outcomes preserved, UNKNOWN rejection | Failure Ledger, Reality Anchor | negative path |

## Claim boundaries

- Not claimed: QuickSpin reduces model/provider latency.
- Not claimed: every user perceives a shorter wait.
- Not claimed: demo simulation is live production AI.
- Not claimed: controlled failure is a live provider outage.
- Not claimed: hosted analytics/extra packs exist today.
