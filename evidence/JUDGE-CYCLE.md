## Reality anchor inside the cycle

`SIGNAL / OPPORTUNITY → REAL NEGATIVE EVENT → OBSERVABLE IMPACT → DESIGN LESSON → RESPONSE / MITIGATION`

All five elements are PASS in `REALITY-ANCHOR.md`. The negative event is the OpenAI June 2–3, 2026 production incident; QuickSpin explicitly refuses to claim it would have prevented or repaired that incident.

## Critical invariants

- **Real failure > fake success.**
- Implementation presence is not execution evidence.
- No evidence → UNKNOWN/refusal, not a gameplay claim.
- Unknown progress stays indeterminate.
- Failure/cancellation are not completion.
- A controlled demo failure is not a live provider outage.
- An expected deployment hostname is not runtime evidence.
- `PROJECT_COMPLETE` is forbidden until terminal reconciliation and every blocking final gate pass.
